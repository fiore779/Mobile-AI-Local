# Mobile AI Local 账号与连接信息的删除

最后更新:{{生效日期}}　开发者:{{开发者名称}}　联系方式:{{联系邮箱}}

本页说明如何删除 Mobile AI Local(以下简称“本应用”)中**通过 Google 登录创建的账号**及其关联的信息。只有在使用设置中的“API 连接”(连接云端 AI)时才需要登录。如果您只使用本地模型,就没有登录,也没有可删除的账号。

## 1. 会被删除的内容
删除账号后,以下信息会被删除:
- **保存在云端(Firebase 的 Cloud Firestore)的 API 连接“元数据”**:服务商类型、显示名称、连接 URL、要使用的模型名称、创建和更新时间
- **本应用的账号(Firebase Authentication 的用户)**:您的 Google 账号邮箱地址和用户 ID
- **您执行删除操作的那台设备上,此账号的 API 连接**:连接列表、已保存的 API 密钥、对云端发送的同意记录

## 2. 不会被删除的内容
- **Google 账号本身**(本应用无法删除您的 Google 账号)
- **设备上的对话历史**(可在“历史记录”页面逐个对话删除;卸载应用也会清除)
- **已下载的模型和设置**
- **云端服务商(Anthropic、OpenAI、Google 等)一侧的账号、API 密钥和已发送的内容**。如需使 API 密钥失效或删除已发送给服务商的内容,请在各服务商的页面或按其流程操作。本应用的开发者无法操作这些内容。
- **其他设备上保存的 API 密钥**:密钥只保存在各设备内。请在其他设备上的应用中删除连接,或卸载应用。

## 3. 在应用内删除的步骤
1. 打开本应用,点击底部的“设置”。
2. 打开“API 连接”。
3. 在已登录的状态下,向下滚动到页面最下方(位于连接列表、“添加连接”和“Gemini 推理量”设置之后),点击**“删除账号和云端连接信息”**(未登录时不显示此按钮;按钮文字以应用显示的语言为准)。
4. 查看确认界面后继续。出于安全考虑,**每次**都会要求您再次确认 Google 账号(重新登录)。如果取消此步骤,则不会删除任何内容。
5. 完成后,第 1 节的信息会被删除,并退出登录。

在没有网络的地方,删除可能失败。请连接网络后重试。

## 4. 无法使用应用时的申请方式
如果您无法操作应用(例如丢失了设备或已卸载应用),可以申请删除:
- **邮件地址:kzt.app.support@gmail.com**
- 邮件主题请写“账号删除申请”。
- **为了确认是您本人,请使用登录本应用时所用的 Google 账号(注册邮箱)发送邮件。** 如果从其他地址发送,我们无法确认身份,可能无法删除。
- 确认后,我们会在合理的期限内删除第 1 节中的云端信息(元数据和 Firebase 账号),并回复告知。

即使通过申请,第 2 节“不会被删除的内容”也无法由我们删除。
