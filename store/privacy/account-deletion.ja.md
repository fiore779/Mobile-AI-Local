# Mobile AI Local アカウントと連携情報の削除

最終更新: {{施行日}}　開発者: {{開発者名}}　連絡先: {{連絡先メールアドレス}}

このページは、Mobile AI Local(以下「本アプリ」)の **Google サインインで作られるアカウント** と、それに紐づく情報を削除する方法を説明します。サインインが必要なのは、設定の「API連携」(クラウドの AI への接続)を使うときだけです。ローカルモデルだけを使っている場合は、サインインしていないため、削除するアカウントはありません。

## 1. 削除されるもの
アカウントを削除すると、次の情報が削除されます。
- **クラウド上(Firebase の Cloud Firestore)に保存された、API連携の「メタデータ」**: 提供元の種類、表示名、接続先 URL、使うモデル名、作成・更新日時
- **本アプリのアカウント(Firebase Authentication のユーザー)**: Google アカウントのメールアドレスとユーザー ID
- **アプリを操作した端末の中の、このアカウントの API連携**: 接続先の一覧、保存された API キー、クラウド送信への同意の記録

## 2. 削除されないもの
- **Google アカウントそのもの**(Google のアカウントは、本アプリでは削除されません)
- **端末の中の会話履歴**(アプリの履歴画面から、会話ごとに削除できます。アンインストールでも消えます)
- **ダウンロードしたモデルと、設定**
- **クラウドの提供元(Anthropic、OpenAI、Google など)側のアカウント、API キー、送信済みの内容**。API キーの無効化や、提供元に送られた内容の削除は、各提供元の画面や手続きで行ってください。本アプリの開発者は、これらを操作できません。
- **他の端末に保存された API キー**: キーは各端末の中にだけ保存されます。他の端末のキーは、その端末のアプリで接続先を削除するか、アンインストールしてください。

## 3. アプリの中で削除する手順
1. 本アプリを開き、下部の「設定」を開く。
2. 「API連携」を開く。
3. サインインしている状態で、画面を下へスクロールし、接続先の一覧・「接続先を追加」・「Gemini の推論量」の設定のさらに下にある **「アカウントとクラウド上の連携情報を削除」** を押す(サインインしていないときは、このボタンは表示されません)。
4. 確認画面で内容を確認して、削除を進める。セキュリティのため、**毎回**、Google アカウントの再確認(再サインイン)を求められます。再確認を取り消すと、何も削除されません。
5. 完了すると、上記 1 節の情報が削除され、サインアウトされます。

通信できない場所では削除に失敗することがあります。ネットワークに接続して、もう一度お試しください。

## 4. アプリを使えない場合の依頼方法
端末を紛失した、アプリを削除した、などでアプリの操作ができない場合は、次の方法で削除を依頼できます。
- **メールの宛先: kzt.app.support@gmail.com**
- 件名に「アカウント削除の依頼」と書いてください。
- **本人確認のため、本アプリのサインインに使った Google アカウント(登録メールアドレス)から、メールを送ってください。** 別のアドレスからの依頼では、本人確認ができないため、削除できないことがあります。
- 確認ができ次第、合理的な期間内に、上記 1 節のクラウド上の情報(メタデータと Firebase のアカウント)を削除し、その旨を返信します。

なお、依頼でも、2 節に書いた「削除されないもの」は削除できません。
