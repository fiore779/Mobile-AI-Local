# Mobile AI Local 隱私權政策

生效日期:{{生效日期}}　開發者:{{開發者名稱}}　聯絡方式:{{聯絡信箱}}

Mobile AI Local(以下簡稱「本應用程式」)是一款在裝置上執行的 AI 聊天應用程式。使用裝置上的模型(本機模型)進行的對話不會離開裝置。僅當您自行設定「API 連接」並選擇雲端 AI 模型時,對話內容才會傳送到您所選的服務商(例如 Anthropic、OpenAI、Google 等)(第 2 節)。無論哪種情況,對話內容都不會傳送到開發者的伺服器。

## 1. 儲存在裝置上的資訊
以下資訊只儲存在本應用程式的專用儲存空間(其他應用程式看不到)。開發者不會收到這些資訊。
- 對話內容(您的提問、AI 的回答、對話標題、系統提示詞)
- 您下載的 AI 模型檔案
- 設定(主題、語言、生成設定、僅在 Wi-Fi 下載等)
- 若您設定了 API 連接:連接資訊(服務商類型、顯示名稱、連接 URL、要使用的模型名稱)以及您輸入的 API 金鑰。API 金鑰使用裝置的加密功能(Android Keystore)加密儲存,除連接服務商時使用外不會傳送到裝置之外,也不在備份範圍內。
- 工作資料夾(應用程式在自己的內部儲存空間中自動建立的專用資料夾)中的檔案。其他應用程式看不到,解除安裝應用程式後會被刪除。開發者不會收到
- 對話摘要(對話變長時會摘要較早的部分,每個對話儲存一份)

## 2. 網路連線
只有當您進行以下操作時,本應用程式才會連線到網際網路。
- **搜尋模型:** 您輸入的搜尋詞會傳送到模型發佈服務 Hugging Face(huggingface.co)。
- **下載模型:** 從 Hugging Face 取得您所選模型的檔案。

在這些連線中,Hugging Face 會收到您的 IP 位址和基本的連線資訊,其處理方式依 Hugging Face 自己的隱私權政策。對話內容絕不會包含在這些連線中。本機模型的所有回答都在裝置上產生,不需要連線。

**連接雲端 AI(API 連接,僅在您設定後):**
- 只有當您在設定中的「API 連接」裡新增連接、選擇其模型並傳送訊息時,本應用程式才會透過 HTTPS 將對話內容(您輸入的文字、同一對話中先前的內容、系統提示詞、生成設定)傳送到您所選服務商的伺服器。新增連接之前,會顯示註明傳送目的地的確認畫面並徵求您的同意(依服務商類型;自訂連接依主機)。您可以撤銷同意。
- 連接 URL 只能使用 HTTPS,不支援未加密的 HTTP 連接。
- 服務商如何處理您傳送的內容,依該服務商的服務條款與隱私權政策。開發者不會收到這些內容。如產生使用費用,取決於您與服務商之間的合約,本應用程式不收費。
- 選擇本機模型期間不會向雲端傳送任何內容。使用雲端 AI 的對話,畫面上會顯示雲朵圖示和連接名稱。

**使用 Google 帳號登入(僅在使用 API 連接時):**
- 設定 API 連接需要使用 Google 帳號登入。僅使用本機模型時,不需要也不會要求登入。
- 登入後,開發者管理的雲端資料庫(Google 的 Firebase Authentication 與 Cloud Firestore)會儲存您的 Google 帳號電子郵件地址與使用者 ID,以及 API 連接的「中繼資料」(服務商類型、顯示名稱、連接 URL、要使用的模型名稱、更新時間)。目的是依帳號記錄連接狀況,並在其他裝置上延續「已連接」的狀態。
- **API 金鑰與對話內容不會儲存在此資料庫中。** 金鑰只存在於各裝置內,因此在其他裝置上需要重新輸入金鑰。
- 這些資料只有您本人的帳號才能存取。

**工作資料夾(僅在您啟用後)與對話摘要:**
- 工作資料夾中檔案的內容只會交給裝置上的模型,不會透過網路傳送。使用雲端 AI 時無法使用工作資料夾,也不會傳送檔案內容(若在裝置內模型讀取過檔案的對話中切換到雲端 AI,讀取結果也會省略後再傳送)。
- 對話變長時會摘要較早的部分;使用雲端 AI 時,會向提供者多傳送一次用於摘要的請求(傳送的內容與一般對話的傳送相同)。
- 使用雲端 AI 時,不會傳送工作資料夾中檔案的內容本身,但 AI 的回覆或對話摘要中可能包含其中一部分。
- 若您分享或匯出工作資料夾中的檔案,所得檔案不再由本應用程式管理(依接收方應用程式或服務的方式處理)。

## 3. 我們不蒐集的內容
使用本機模型時,本應用程式不要求註冊帳號;只有在使用 API 連接時才會要求使用 Google 帳號登入(第 2 節)。本應用程式不含廣告、使用情況分析、當機資訊回報,也沒有任何追蹤您的機制。本應用程式不會存取您的位置、聯絡人、相片、麥克風或相機。 本應用程式不會存取裝置上除工作資料夾(應用程式內部儲存空間)以外的檔案。

## 4. 使用的權限
- 網際網路:用於搜尋和下載模型,以及與您設定的雲端 AI 通訊
- 網路狀態:用於判斷「僅在 Wi-Fi 下載」
- 前景服務:在 AI 產生回答(雲端 AI 則為接收回答)期間,即使離開應用程式也繼續進行(Android 13 以上不會顯示通知;Android 12 以下會顯示一則最小化、不顯眼的通知)
- 儲存空間權限:不使用。工作資料夾位於應用程式的內部儲存空間中。分享和匯出只在您操作時,透過 Android 的分享畫面和儲存位置選擇畫面進行

## 5. 檢舉不當內容
如果 AI 的回答有問題,您可以使用本應用程式的檢舉功能聯絡開發者。該功能會在您的郵件應用程式中建立一封包含所檢舉回答的郵件草稿。**只有您自己傳送後,開發者才會收到。**

## 6. 刪除資訊
- 您可以隨時在「歷史記錄」頁面刪除對話。
- 您可以在「模型」頁面刪除已下載的模型。
- 您可以隨時在設定中的「API 連接」裡刪除連接。刪除後,對應的 API 金鑰也會從裝置上清除。
- 與您的 Google 帳號關聯的資訊(電子郵件地址、使用者 ID、API 連接的中繼資料)可隨時透過設定中的「刪除帳號與雲端連線資訊」刪除。操作步驟、會被刪除和不會被刪除的內容,以及無法使用應用程式時的申請方式,請見刪除頁面:{{刪除頁面URL}}(申請信箱:kzt.app.support@gmail.com)
- 解除安裝本應用程式後,本應用程式儲存在裝置上的所有資訊都會被清除(與 Google 帳號關聯的資訊請依上述方式另行刪除)。
- 已傳送到雲端服務商的內容,其刪除依各服務商自己的流程。
- 工作資料夾中的檔案位於應用程式的內部儲存空間中,解除安裝應用程式後會被刪除。可以在「設定 > 工作資料夾」中逐一或全部刪除檔案。已分享或匯出的檔案在解除安裝後仍會保留。
- 刪除對話時,該對話的摘要也會一併刪除。

## 7. 關於 AI 的輸出
AI 的回答可能有錯誤或不當之處。重要的事情請自行確認。本應用程式不內建 AI 模型,由您自行安裝;遵守所安裝模型的授權(使用條款)是您自己的責任。
