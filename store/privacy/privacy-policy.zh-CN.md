# Mobile AI Local 隐私政策

生效日期:{{生效日期}}　开发者:{{开发者名称}}　联系方式:{{联系邮箱}}

Mobile AI Local(以下简称"本应用")是一款在设备上运行的 AI 聊天应用。使用设备上的模型(本地模型)进行的对话不会离开设备。仅当您自行设置“API 连接”并选择云端 AI 模型时,对话内容才会发送到您所选的服务商(例如 Anthropic、OpenAI、Google 等)(第 2 节)。无论哪种情况,对话内容都不会发送到开发者的服务器。

## 1. 保存在设备上的信息
以下信息只保存在本应用的专用存储空间(其他应用看不到)。开发者不会收到这些信息。
- 对话内容(您的提问、AI 的回答、对话标题、系统提示词)
- 您下载的 AI 模型文件
- 设置(主题、语言、生成设置、仅在 Wi-Fi 下载等)
- 若您设置了 API 连接:连接信息(服务商类型、显示名称、连接 URL、要使用的模型名称)以及您输入的 API 密钥。API 密钥使用设备的加密功能(Android Keystore)加密保存,除连接服务商时使用外不会发送到设备之外,也不在备份范围内。

## 2. 网络连接
只有当您进行以下操作时,本应用才会连接互联网。
- **搜索模型:** 您输入的搜索词会发送到模型分发服务 Hugging Face(huggingface.co)。
- **下载模型:** 从 Hugging Face 获取您所选模型的文件。

在这些连接中,Hugging Face 会收到您的 IP 地址和基本的连接信息,其处理方式遵循 Hugging Face 自己的隐私政策。对话内容绝不会包含在这些连接中。本地模型的所有回答都在设备上生成,无需联网。

**连接云端 AI(API 连接,仅在您设置后):**
- 只有当您在设置中的“API 连接”里添加连接、选择其模型并发送消息时,本应用才会通过 HTTPS 把对话内容(您输入的文字、同一对话中此前的内容、系统提示词、生成设置)发送到您所选服务商的服务器。添加连接之前,会显示注明发送目的地的确认界面并征求您的同意(按服务商类型;自定义连接按主机)。您可以撤销同意。
- 连接 URL 只能使用 HTTPS,不支持未加密的 HTTP 连接。
- 服务商如何处理您发送的内容,遵循该服务商的服务条款和隐私政策。开发者不会收到这些内容。如产生使用费用,取决于您与服务商之间的合同,本应用不收费。
- 选择本地模型期间不会向云端发送任何内容。使用云端 AI 的对话,画面上会显示云图标和连接名称。

**使用 Google 账号登录(仅在使用 API 连接时):**
- 设置 API 连接需要使用 Google 账号登录。仅使用本地模型时,不需要也不会要求登录。
- 登录后,开发者管理的云端数据库(Google 的 Firebase Authentication 和 Cloud Firestore)会保存您的 Google 账号邮箱地址和用户 ID,以及 API 连接的“元数据”(服务商类型、显示名称、连接 URL、要使用的模型名称、更新时间)。目的是按账号记录连接状况,并在其他设备上延续“已连接”的状态。
- **API 密钥和对话内容不会保存在此数据库中。** 密钥只存在于各设备内,因此在其他设备上需要重新输入密钥。
- 这些数据只有您本人的账号才能访问。

## 3. 我们不收集的内容
使用本地模型时,本应用不要求注册账号;只有在使用 API 连接时才会要求使用 Google 账号登录(第 2 节)。本应用不含广告、使用情况分析、崩溃信息上报,也没有任何追踪您的机制。本应用不会访问您的位置、通讯录、照片、麦克风或相机。

## 4. 使用的权限
- 互联网:用于搜索和下载模型,以及与您设置的云端 AI 通信
- 网络状态:用于判断"仅在 Wi-Fi 下载"
- 前台服务:在 AI 生成回答(云端 AI 则为接收回答)期间,即使离开应用也继续进行(Android 13 及更高版本不会显示通知;Android 12 及更低版本会显示一条最小化的、不显眼的通知)

## 5. 举报不当内容
如果 AI 的回答有问题,您可以使用本应用的举报功能联系开发者。该功能会在您的邮件应用中创建一封包含所举报回答的邮件草稿。**只有您自己发送后,开发者才会收到。**

## 6. 删除信息
- 您可以随时在"历史记录"页面删除对话。
- 您可以在"模型"页面删除已下载的模型。
- 您可以随时在设置中的“API 连接”里删除连接。删除后,对应的 API 密钥也会从设备上清除。
- 与您的 Google 账号关联的信息(邮箱地址、用户 ID、API 连接的元数据)可随时通过设置中的“删除账号和云端连接信息”删除。操作步骤、会被删除和不会被删除的内容,以及无法使用应用时的申请方式,请见删除页面:{{删除页面URL}}(申请邮箱:kzt.app.support@gmail.com)
- 卸载本应用后,本应用保存在设备上的所有信息都会被清除(与 Google 账号关联的信息请按上述方式另行删除)。
- 已发送到云端服务商的内容,其删除遵循各服务商自己的流程。

## 7. 关于 AI 的输出
AI 的回答可能有错误或不当之处。重要的事情请自行核实。本应用不自带 AI 模型,由您自行安装;遵守所安装模型的许可证(使用条款)是您自己的责任。

## 8. 儿童
本应用的主要对象不是 13 岁以下的儿童。
