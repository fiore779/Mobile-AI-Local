# Mobile AI Local 帳號與連接資訊的刪除

最後更新:{{生效日期}}　開發者:{{開發者名稱}}　聯絡方式:{{聯絡信箱}}

本頁說明如何刪除 Mobile AI Local(以下簡稱「本應用程式」)中**透過 Google 登入建立的帳號**及其關聯的資訊。只有在使用設定中的「API 連接」(連接雲端 AI)時才需要登入。如果您只使用本機模型,就沒有登入,也沒有可刪除的帳號。

## 1. 會被刪除的內容
刪除帳號後,以下資訊會被刪除:
- **儲存在雲端(Firebase 的 Cloud Firestore)的 API 連接「中繼資料」**:服務商類型、顯示名稱、連接 URL、要使用的模型名稱、建立與更新時間
- **本應用程式的帳號(Firebase Authentication 的使用者)**:您的 Google 帳號電子郵件地址與使用者 ID
- **您執行刪除操作的那台裝置上,此帳號的 API 連接**:連接清單、已儲存的 API 金鑰、對雲端傳送的同意紀錄

## 2. 不會被刪除的內容
- **Google 帳號本身**(本應用程式無法刪除您的 Google 帳號)
- **裝置上的對話歷史記錄**(可在「歷史記錄」頁面逐個對話刪除;解除安裝應用程式也會清除)
- **已下載的模型和設定**
- **雲端服務商(Anthropic、OpenAI、Google 等)一側的帳號、API 金鑰與已傳送的內容**。如需使 API 金鑰失效或刪除已傳送給服務商的內容,請在各服務商的頁面或依其流程操作。本應用程式的開發者無法操作這些內容。
- **其他裝置上儲存的 API 金鑰**:金鑰只儲存在各裝置內。請在其他裝置上的應用程式中刪除連接,或解除安裝應用程式。

## 3. 在應用程式內刪除的步驟
1. 開啟本應用程式,點選底部的「設定」。
2. 開啟「API 連線」。
3. 在已登入的狀態下,向下捲動到頁面最下方(位於連線清單、「新增連線」與「Gemini 推理量」設定之後),點選**「刪除帳號與雲端連線資訊」**(未登入時不會顯示此按鈕;按鈕文字以應用程式顯示的語言為準)。
4. 查看確認畫面後繼續。基於安全考量,**每次**都會要求您再次確認 Google 帳號(重新登入)。若取消此步驟,則不會刪除任何內容。
5. 完成後,第 1 節的資訊會被刪除,並登出。

在沒有網路的地方,刪除可能失敗。請連上網路後重試。

## 4. 無法使用應用程式時的申請方式
如果您無法操作應用程式(例如遺失了裝置或已解除安裝應用程式),可以申請刪除:
- **電子郵件:kzt.app.support@gmail.com**
- 郵件主旨請寫「帳號刪除申請」。
- **為了確認是您本人,請使用登入本應用程式時所用的 Google 帳號(註冊信箱)寄送郵件。** 若從其他地址寄送,我們無法確認身分,可能無法刪除。
- 確認後,我們會在合理的期限內刪除第 1 節中的雲端資訊(中繼資料與 Firebase 帳號),並回覆告知。

即使透過申請,第 2 節「不會被刪除的內容」也無法由我們刪除。
